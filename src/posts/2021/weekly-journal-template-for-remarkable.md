<p>I just watched this video, and I would like to give this journal system a try. But I don't want to buy a notebook just yet, so I whip up a simple reMarkable template for that.</p><figure class="kg-card kg-embed-card"><iframe width="200" height="113" src="https://www.youtube.com/embed/31Wq_qv0dZM?feature=oembed" frameborder="0" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture" allowfullscreen></iframe></figure><h2 id="how-to-add-template-to-remarkable">How to add template to reMarkable</h2><p>The awesome folks at <a href="https://remarkablewiki.com/tips/templates">reMarkableWiki has wrote down exactly how to create template</a>, as well as <a href="https://remarkablewiki.com/tech/ssh">how to SSH into the tablet</a>. I do have a few extra notes that I want to add, mostly because I am using a Windows machine:</p><ul><li>It looks like Windows Terminal / PowerShell 7 has <code>ssh</code> built-in. Alternatively, you can use PuTTY</li><li><a href="https://unix.stackexchange.com/a/106482/314936">StackOverflow answer</a> on how to copy file from your machine to another SSH machine</li></ul><h2 id="tips-on-creating-template">Tips on creating template</h2><p>Apart from the notes in the reMarkableWiki (mentioned above 👆), here are a few extra notes:</p><ul><li>You don't need fancy software for that, Figma is perfectly adequate for that</li><li>Remember to put a background (Just <code>#FFFFFF</code> is fine). Otherwise the eraser seems to get really confused and turn everything black</li><li>For horizontal template, rotate it by 90 degrees (see the example below)</li></ul><hr><p>This is the template. Just save as image and you should be good to go.
