<div class="kg-card kg-callout-card kg-callout-card-grey"><div class="kg-callout-emoji">‼️</div><div class="kg-callout-text">Update: full review is up <a href="/galaxy-book-go-review/">here</a></div></div><p>I bought yet another gadget again, this time it's a LTE-enabled ARM-based Windows laptop</p><hr><p>My main intention is to use this as my writing laptop, no matter where I am, I will be able to not only write, but also research on the topics that I am writing. So before jumping into it, let's give it a few a quick look.</p><hr><h2 id="part-1-the-laptop">Part 1: The laptop</h2><p>The laptop I purchased is a Samsung Galaxy Book Go</p><ul><li>Qualcomm Snapdragon 7c</li><li>4GB RAM</li><li>128GB storage</li><li>LTE-enabled</li></ul><p>So not the most impressive hardware for sure. However, I am hoping between the low-power hardware and fan-less design, I will be able to use it comfortably use it anywhere I want (incl. on my lap) for extended amount of time. And so far, I have been using the laptop for about 3 hours, and it's currently sitting on my lap, so it seems to check out so far</p><p>And the biggest reason why I got this laptop is because of it's LTE. The worst part of working in coffee shop is always the Wi-Fi, and with my unecessarily large data plan, I am hoping this can be an issue of the past. And it's also so far working mostly fine. It did took a while to get the network setup corretly (a bunch of software issue that I will talk about below), </p><figure class="kg-card kg-image-card kg-width-wide"><img src="/assets/images/downloaded_images/2021/10/image-2.png" class="kg-image" alt="Screenshot of the &quot;Network &amp; Internet&quot; settings screen, in which it shows the devices is connected to &quot;Mobile (o2 - de)&quot;" loading="lazy" width="1032" height="235" ></figure><p>And unlike iPad, this actually has a (mostly) functional full-feature OS, and the whole device is cheaper than the keyboard. On the otherhand, I get this insetad of Chromebook, because a) there ain't much LTE-enabled Chromebooks I can see, and b) I was scared by my Pixel Slate's terrible experience. So no Chromebook for me for the forseeable future.</p><hr><h2 id="part-2-the-software">Part 2: The software</h2><p>There are 2 main part of the software: Windows on ARM, and Windows 11.</p><p>My first impression is that while Windows on ARM definitely has quite a bit of potential (not as buggy as I would expect for such a low-level changes), it also definitely suffers from the lack of native software. And that is particularly important on this device, since the 7c SoC is not the fasting thing around, and I am avoiding using x86/x64 software as much as possible, especially things that's design to run in the task bar. That means</p><ul><li>No Spotify (just stream from my phone)</li><li>No Toggl Track (just run from my phone)</li><li>No Todoist (just use the web)</li><li>No Bitwarden (just use the browser extension)</li></ul><p>And it is particularly annoying if you don't want to jump to Edge or other Chromium-based browsers, which has PWA support to simulate a few of those apps. <a href="https://9to5google.com/2021/01/27/firefox-discontinues-work-pwa-desktop/">I am looking at you Firefox</a> 👈👀</p><figure class="kg-card kg-image-card kg-card-hascaption"><img src="/assets/images/downloaded_images/2021/10/image-3.png" class="kg-image" alt loading="lazy" width="602" height="221" ><figcaption>There ain't much apps I need to pin, since almost everything is in the browser anyway 🤷</figcaption></figure><p>And for Windows 11, I actually have been using it on my main desktop for a while now, and I don't have much complaint so far. There are definitely quite a few bugs to sort out, especially around the Qualcomm networking drivers. But I am not sure if that's just Qualcomm being Qualcomm, or something Windows 11 is not good at. There is 1 thing that I will missed out on, which is the Android app support. Apparently it will require at least 8GB RAM, which is unfortunate but understandable. </p><hr><p>This is my first impression of the device so far, let's see if I have enough strong opinion to write a full review for this device in the future 🤞</p><hr><p><u>Update (2021.10.07)</u>: I collected the list of apps I have used/tried/saw working into <a href="https://louis993546.github.io/Is-it-ready-for-Windows-ARM64/">this little page</a> (<a href="https://github.com/louis993546/Is-it-ready-for-Windows-ARM64">Source</a>), hope that is helpful to someone 🤗</p>
